# 自适应布局审查

本轮从 22 个 Slint 文件中逐项审查了 148 行包含小数像素或百分比的源码。截图中的小数坐标不再作为布局输入；保留设计规定的控件尺寸、内边距、间距和断点，由文字度量和可用空间决定排列。

| 区域 | 布局依据 |
| --- | --- |
| 首页、侧栏、歌曲列表 | 文字行高由共享 `FlowText` 度量；虚拟列表与可见歌曲行共用 `SongMetrics`；菜单高度按内容计算 |
| 全屏播放器 | Flex 布局在横排、竖排之间切换；封面取可用宽高的较小值；标题、歌手、进度条与按钮纵向排列 |
| 搜索页 | 标题自然高度；分类网格按最小列宽计算列数；旋转装饰使用真实矩形与旋转属性 |
| 歌手页 | 标题、标签、发行信息和区块间距依赖实际内容；窄窗口头像与介绍上下排列 |
| 歌单、专辑、本地音乐详情 | 头部随文字增高，操作栏按可用宽度换行，按钮宽度由文字与图标决定 |
| 登录、歌单编辑、添加歌单 | 表单按内容排列；长错误信息和短窗口可滚动；编辑弹窗的页头、页脚与滚动表单分别布局 |
| 设置 | 页头、分组标题、说明和设置行由内容撑开；右侧操作控件按实际尺寸对齐 |

`ClampedText` 共用多行省略文字的行框及绘制空间计算，处理字体上下伸部与紧凑行距的差异。详情标题和歌手发行标题均检查两行的实际文字像素，避免只预留两行高度却丢失一行内容。

`python3 scripts/check_ui_quality.py` 拒绝属性绑定、默认值、赋值中的小数 `px` / `%` 常量，包括自定义长度属性。无单位行距、缩放、动画曲线及透明度不属于固定布局坐标。源码中保留的 `0.05px` 是歌词鼠标移动比较阈值，不参与任何布局计算。

- 详情页：1435×1000、1340×960、1100×800、950×800、620×720；长标题、简介、操作栏换行、无重叠、封面比例以及标题的两行文字像素。

- 编辑弹窗：1435×1000、620×720、620×420；错误信息换行、表单滚动、底部按钮可见。
- 登录：长错误信息下滚动后可以到达提交按钮。
- 搜索分类：1435、1340、1000、620 宽度；列数、卡片间距、边界与不重叠。

现有设置窗口、歌词跟随、虚拟列表复用、菜单锚点、登录动画和歌单操作测试继续运行。历史 Electron 截图坐标只用于未改变的固定控件及动画；受本轮影响的动态布局使用内容、包含关系和相邻组件位置断言。

歌曲菜单的下一曲、下载、添加到歌单、删除操作共用 `ui/components/menu_item.slint`，由横向布局统一图标、文字及箭头的位置，行高按内容测量。`src/layout_tests.rs` 检查亮暗主题、宽窄窗口下的文字列对齐、图标与文字垂直居中，以及长歌单名称与歌曲数量不重叠。歌单页和搜索页滚动时关闭菜单并重置展开状态；菜单内部滚动（包括到达底部后继续滚动）保持打开，后台页面不跟随滚动。运行 `cargo test --locked song_context_menu`；可用 `NCM_SLINT_SCREENSHOT_DIR` 输出对应截图。
