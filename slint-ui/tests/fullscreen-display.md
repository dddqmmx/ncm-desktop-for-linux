# 全屏封面与歌词验证

## 2026-11-10：进度条起点与恢复歌曲的歌词

全屏进度条的播放段、缓冲段缺少左侧锚点，导致 Slint 将它们居中；现在显式锚定轨道起点，宽度继续根据百分比和可用宽度计算。鼠标左键点击和拖动执行跳转，越过两端时限制到 0–100%，右键不会跳转。

恢复播放列表时原先只显示歌曲信息并清空歌词，歌词请求仅在开始播放时发送。现在歌曲展示共用 `src/runtime/view/lyrics.rs` 的加载入口，恢复的在线歌曲也会加载歌词并定位到保存的进度，音频仍等待用户点击播放。歌词请求随歌曲切换失效，避免旧结果覆盖新歌；进度条跳转、歌词跳转和播放快照共用定位方法，暂停或尚未启动音频时也能立即更新高亮和滚动位置。

新增回归分别在修复前复现进度段居中、恢复后没有歌词请求。进度测试覆盖 1435、1100、800px 窗口的起点和比例、点击、连续拖动、边界与右键；恢复测试覆盖空面板异步收到歌词、保存位置居中、暂停跳转、重新打开全屏、空闲快照保护和迟到结果失效。接口响应使用测试数据，截图通过软件后端生成；不依赖真实账号或播放真实音频。

2026-11-08，对照项目内 Electron 的 `LyricPanel.vue`、实际 DOM 几何和截图，验证 Slint 全屏播放器。测试使用模拟数据与临时配置，不读取真实账号。

## 修复内容

- 全屏封面进入页面、切换歌曲时独立请求 1600px 图片；卡片继续使用 800px，列表使用 128px。解码保持比例，不把小源图放大。迟到的缩略图不会覆盖高清图。
- 原先固定的歌词行高改为实际文字、发音、译文的高度之和；可选内容为空或被关闭时不占位。原文行高 36.4px、发音 20.25px、译文 21.6px，组内间隔 4px，上下内边距各 10px，相邻歌词间隔 12px。长句按实际换行数增长。
- 只有时间戳或空白字符的 LRC 行会被过滤；否则每个句间标记都会成为一整行空白。译文和发音按 Electron 规则匹配首个时间差小于 350ms 的非空项，避免时间精度差异导致内容丢失。
- 激活歌词缩放到 1.1 倍、过渡 350ms，不改变行的布局高度。播放位置驱动滚动；手动滚动吸附到最近歌词并显示跳转提示，停止操作 3 秒后恢复跟随。跳转、切换歌词显示选项和窗口尺寸变化会重新定位。运行时使用与 Electron 相同的 50ms 歌词提前量。

## 验证结果

`fullscreen-ground-truth.json` 来自实际 Electron 窗口。采集数据包含空时间戳，检查最终只保留 5 行非空歌词；分别记录初始显示、下一句跟随、关闭译文、关闭所有附加行。

在 627.5×836 的歌词视口中，Electron 三行组合的布局高度为 106.234375px，Slint 为 106.25px；初始激活行中心分别为 417.5703px 和 418px。回归检查行高和中心位置，并使用 80 行混合歌词检查无译文行、长句换行、相邻间隔、手动滚动期间不抢位置、恢复跟随及大幅跳转。

真实 Wayland 窗口测试使用 1600×1600 高频图案封面和 80 行混合歌词。截图确认封面细节和圆角正常、换行内容完整；几何检查确认相邻歌词间隔为 12px。一次实测的跟随中/结束后中心为 499.86664px / 418.6667px，最终位置与视口中心一致；手动滚动后能恢复跟随。截图读取可能耗时数百毫秒，因此动画计时从截图完成后的状态切换开始。

封面另有独立回归验证：已存在 128px 图时仍发出 1600px 请求、全屏切歌重新请求、1600px 解码保留尺寸，以及随后收到 800px/128px 图片时不降级。真实窗口使用合成封面，未验证具体线上歌曲的源图质量。

这不是逐像素一致性保证。Slint 当前使用整行透明度近似边缘渐隐，Electron 使用逐像素遮罩；字体栅格化、文字发光和模糊也仍有差异。自动跟随使用 350ms 缓动，未宣称复刻 Chromium 原生滚动每一帧的轨迹。软件截图的圆角裁剪表现与真实桌面后端不同。

## 悬停与中心指示

追加使用 Electron `webContents.sendInputEvent` 的真实鼠标移动和滚轮事件采集 `interaction` 基准。原版滚动后保留之前的 CSS 悬停行，直到鼠标实际移动；Slint 默认会在布局移动后重新命中鼠标下方的行。现在记录窗口坐标，只在指针实际移动或离开面板时更新悬停目标，忽略滚动布局产生的同坐标移动通知。

原版实测：普通悬停透明度 0.65、手动滚动中心行 0.75、中心行同时悬停 0.9，播放行始终为 1。中心时间与播放按钮由距离视口中心最近的行决定；换行和译文导致高度不同的行，以相邻中心点的中点为分界，恰好相等时选择后行。测量值仅在布局变化时更新，滚动时读取相邻行中心。

中心指示线恢复为虚线，时间和播放按钮距面板左右边缘各 12px，修复了原先两个控件挤在中央、指示线未撑开的布局；提示文字分别为“跳转到 m:ss 播放”和“从此处播放”。滚动时收起文字提示，停止后允许悬停显示。提示使用面板内单个透明输入浮层，停留 500ms 后显示，避免原生提示窗口在 Wayland 上产生额外的进入/离开事件；浮层不会遮挡歌词点击或滚轮。时间及虚线区域放行点击，播放按钮转发滚轮；加载时隐藏指示器并禁用跳转，右键点击歌词、按钮或面板空白处可恢复跟随。恢复计时在吸附动画期间继续续期，与 Electron 的滚动处理一致。

自动回归检查固定鼠标滚动、移动 1px 后更新悬停、中心行叠加高亮、实际提示浮层、加载状态、指示线点击穿透、按钮滚轮与跳转、长短行混排的最近中心选择及空白处右键取消。真实窗口测试另外记录 `fullscreen-real-hover-centered.png` 和 `fullscreen-real-hover-scroll.png`，并检查提示浮层已经显示；提示包含在主窗口截图中。

## 复测

在 `slint-ui` 目录运行：

```sh
cargo test --locked --offline -- --test-threads=1
NCM_SLINT_SCREENSHOT_DIR=/tmp/ncm-fullscreen-review timeout 60s cargo test --locked --offline real_fullscreen_artwork_and_lyric_follow -- --ignored --nocapture --test-threads=1
```

真实窗口测试需要访问 Wayland/X11 桌面。截图输出为 `fullscreen-real-initial.png`、`fullscreen-real-follow.png`、`fullscreen-real-hover-centered.png`、`fullscreen-real-hover-scroll.png`。

Electron 已构建后，使用独立临时配置重新采集基准：

```sh
NCM_ELECTRON_SCREENSHOT_DIR=/tmp/ncm-fullscreen-review timeout 35s ../../electron/node_modules/.bin/electron --no-sandbox scripts/extract-electron-metrics.cjs --fullscreen-player
```

输出 `tests/fullscreen-ground-truth.json` 及初始、跟随、关闭译文、关闭所有附加行四张截图。
